# 批阅 · AI 全卷批阅 · 第一阶段需求文档

版本：v0.1｜日期：2026-10-15｜状态：依据本轮讨论形成的需求基线，尚未开发、尚未验收。

配套文档：[第一阶段开发文档](批阅-AI全卷批阅-第一阶段开发文档.md)。本文件定义业务效果和验收边界；字段、接口、算法候选和开发顺序见配套文件。

## 1. 目标

在已有快速录入系统中，选择一份已结构化的标准卷，拖入同一学生的多页手机扫描照片；系统校正页面、识别学生作答，再将作答文字和标准题目数据合并为一次全卷文字评分请求，返回逐题得分、理由和可在卷面查看的标记，供老师检查、改分。

第一阶段重点验证真实手写数学作答的识别、匹配和批阅效果，以及整份卷子的处理成本。不得把“文字评分”理解为直接把整卷照片交给评分模型。

## 2. 本轮已确认的决策

| 编号 | 已确认事项 |
|---|---|
| D01 | 接入当前快速录入系统，复用标准卷的结构化题目和原卷资料，不重新录入同一份标准卷。 |
| D02 | 一次只处理一个学生的一份卷子，多张照片属于一次提交。当前用于测试批阅效果，不做全班批量归卷。 |
| D03 | 电脑端拖拽上传；照片来自手机相机或扫描全能王等工具，不开发手机端适配。 |
| D04 | 学生直接写在原卷上；每页左上角会写姓名，姓名可作为识别、核对信息。 |
| D05 | 优先支持清晰、较平整的扫描照片；倒置、轻微偏移等自动处理，严重质量问题提示重拍。 |
| D06 | 先识别学生作答数据，再发送文字给 AI 评分；一份完整试卷正常首轮只发起一次全卷评分调用。识别阶段的调用与费用独立统计。 |
| D07 | 有评分标准时按评分标准执行；没有评分标准时，AI 根据题目、标准答案、解析和该题满分判断，并说明理由，无需老师先确认一份生成标准。 |
| D08 | 图片多模态评分以后只用于需要判断学生作图的部分，第一阶段不开发。 |
| D09 | 客观题和可用文字表达作答的主观题均在本期范围；不退化为只批选择题。 |

## 3. 范围及非目标

### 3.1 第一阶段范围

- 从试卷库选择标准卷，复用其题干、图片引用、选项、小问、答案、解析、题型、分值、区域及可用标签。
- 一名学生的一份多页卷子，上传 JPG/JPEG、PNG 图片。
- 自动方向纠正、页序匹配、必要的对齐校正和图片质量检查。
- 多页手写文字、选择答案、填空和数学公式识别；保留步骤与跨页延续关系。
- 一次全卷文字评分；逐题理由、结果校验、费用与耗时记录。
- 查看学生卷面、识别结果和评分结果；人工改分、保存机器原分与修订记录。
- 明确显示无法识别、缺页、题目匹配不确定、作图待人工等情况。

### 3.2 本期不开发

- 多人混合上传、自动分班归卷、全班同题联合评分、逐题评分模式及两模式对比界面。
- 手机端上传适配、扫描仪连续进纸、自动登录或调用扫描全能王。
- 学生作图的多模态评分、对严重模糊或严重弯曲照片的强行修复。
- 正式学生名单、学号认证、家长或学生发布、学情分析、讲评和导出。
- 为批阅重建快速录入、知识点目录、已有编辑器或生产权限系统。

扫描 PDF 的上传兼容可沿用现有能力评估，但不作为第一阶段手机照片闭环的必过验收项，不据此扩大交付范围。

## 4. 业务定义

| 术语 | 定义 |
|---|---|
| 标准卷 | 快速录入保存的某个正式试卷版本，关联该版本题目、标准答案、分值和原卷页面。 |
| 一次提交 | 一个学生针对选定标准卷上传的一组页面；几张照片不等于几次评分。 |
| 作答识别 | 从学生图片读取实际作答，输出文字、公式和位置；不负责给分，不替学生补步骤。 |
| 全卷评分 | 将可评分题目的标准数据和学生作答文字，在一个评分请求中发送给文字模型。 |
| 作图部分 | 必须查看学生绘制、补画或标注的图形才能判断的部分；不等于“题干中存在插图”。 |
| 未作答 | 对应区域完整、清晰且已检查，能确认学生未写答案；区别于没拍到或识别失败。 |
| 已评分合计 | 当前已有有效分数的合计，存在未评分部分时不作为全卷最终总分。 |

PDF 物理页与印刷页码分别处理。样本一个横向页面包含左右两个印刷页，不应直接按印刷页码计算照片数。

## 5. 用户流程

选择已入库标准卷 → 拖入同一学生的全部图片 → 系统转正、对应页面并检查质量 → 自动识别作答和匹配题目 → 一次全卷文字评分 → 查看卷面标记、逐题作答和评分理由 → 人工核对或改分。

正常清晰图片不要求老师逐页确认后才能继续。需要补拍、匹配不确定或数据不完整时，说明问题所在，提供修正入口。

## 6. 功能需求

### FR01 标准卷选择与复用

使用快速录入正式入库的试卷版本，不直接把旧机器初稿当作最新人工结果。批阅开始后固定引用及必要快照，后续改题、改答案不改变历史批阅依据。

显示题数、满分和资料问题。有知识点则使用，没有正式目录不阻断。缺少答案、分值或必要题意时明确指出，不编造标准数据。

### FR02 单份多图上传

支持拖拽和文件选择；多图归入同一次提交，刷新后可找回处理状态。保留原照片，不用校正图覆盖原图。问题页面可单独替换，不要求重新上传全部图片。

姓名识别作为辅助信息，不建立正式身份认证要求，不因没有读出姓名就禁止测试批阅；如果识别到不同姓名，提示老师核对，不擅自合并为已确认身份。

### FR03 页面检查和校正

自动处理倒置及横拍，匹配标准卷的页面顺序；轻微旋转、缩放、平移、透视偏差进行必要校正。

输出可理解的质量结论和原因。模糊、严重缺边、错误卷面或无法可靠对齐时，明确是哪张有问题并提示替换；不继续硬切、硬批。

检查缺页和重复页。内容相同的重复照片可去重并保留处理记录；只有相似而不能确认重复时提示核对，不静默删除。缺页默认先提示补齐，不把未上传部分当作空白作答给零分。

### FR04 学生作答识别

读取学生实际写出的文字、选项、填空、公式和解题步骤；数学公式应能以 LaTeX 等可传输形式保留。作答需对应稳定题目标识和小问，按正确阅读顺序组合跨栏、跨页内容。

保留作答在卷面中的位置、无法辨认的位置和识别原结果。不得利用标准答案“修正”成学生没有写出的步骤，不将题干、示例解法或印刷答案当作学生作答。

能区分未作答、看不清、缺页、尚未支持的图形作答。识别不确定的部分不假装已识别成功。

### FR05 一次全卷文字评分

正常首轮把本卷可评分题目合成一次文字请求，不逐题调用评分模型，不发送照片、图片附件或通过工具让评分模型取图。

输入包含题干、选项、小问、必要图形语义、标准答案、解析、满分、已有评分标准，以及识别后的学生作答；与该卷无关的答案和其他卷子不发送。

有评分标准就遵循；无评分标准允许 AI 自主判分，理由须对应学生实际作答。不同但正确的解法应按题意评判，不能仅凭与参考答案文字不同扣分。

每个纳入评分的题目必须有结果：得分、满分、给分或扣分理由，或明确的无法评分状态。看不清不等于错误，明确空白作答可以给零分并说明未作答。

一次评分不是一次总处理调用：识别、失败重试可能产生其他费用，全部单独记录。异常重试不冒充“零额外成本的一次成功调用”。

### FR06 图形相关边界

题干带图、学生用文字解答的题仍可纳入本期，但前提是已有结构化文字足以表达必要条件。不能只把图片地址当成图形语义；条件不足时标记待核对。

需要判断学生画图的部分标记“作图部分待人工评分”，本期不调用多模态评分。

混合题优先按明确的小问边界处理。有明确的小问分值、且文字部分可独立判断时，可以对文字部分评分；没有可靠分值拆分时，建议默认整题待人工，不自行分配小问满分。此为本期工程默认，非新增的用户评分规则。

### FR07 结果校验与总分

校验题目标识、题目覆盖、分值范围、评分理由和重复结果。模型遗漏结果时明确标记，不能以零分填齐；不允许同一道题或父题与小问重复计入总分。

无评分依据的数值不能显示成有效机器分。越界分保留原值并告警，按合法区间给出修正建议，未经处理不能呈现为无异常的最终结果。

总分由系统根据有效单项结果计算，不采用模型声称的总分。所有应计分部分均有有效机器分或人工分后，才显示完整总分；人工是否已复核另行标记。

### FR08 查看与人工修订

能查看学生原照片、校正图、逐题识别作答、AI 得分/满分、理由、异常和卷面标记，能定位到对应题目。

人工改分保留原因及历史，机器原分不得覆盖。支持补拍或修正单份学生卷的区域/匹配信息，不把个别学生卷的调整写回标准卷模板。

建议默认布局：左侧校正卷面及标记，右侧题目、识别作答和评分依据，原照片可切换查看。第一阶段至少提供题目级对错、得分和文字批注；只有保留可靠步骤位置时才提供步骤级标注，不虚构笔画位置。布局和标注细度为工程建议，未被另行确认为逐步骤精确批注承诺。

### FR09 状态、恢复、耗时与费用

显示上传、页面检查、作答识别、全卷评分、待核对、失败等阶段及实际原因。浏览器关闭不应使已提交任务丢失；保留可复用的已完成结果。

费用分别显示识别、评分、重试和合计，附调用次数、耗时、可用 token/页数等依据；未知价格或用量标记未知，不能填零假装免费。缓存复用不能掩盖此前实际发生的费用。

## 7. 与快速录入的接入要求

1. 标准数据以已入库版本为基础；图片、公式和跨页区域保持来源可追溯。
2. 当前教辅卷/作业模式有正式原卷模板；普通整卷缺模板，不能自动等同于已支持。第一版优先教辅卷/作业，其他模式须通过同等资料检查后再扩展。
3. 标准卷内容框和推定作答框是定位辅助，不代表学生笔迹已识别，也不代表题框绝对准确。
4. 本期不得因已有区域就裁掉小问间空白、续页步骤、题干括号内或图旁的学生文字。
5. 既有图片、答案或分值问题只对相关题目报错，不默默变成低分。

## 8. 验收标准

下表是本期交付行为检查；自动排序、单页替换等工程默认也需在实现后验证。模型准确率、单卷价格和秒数没有约定数值门槛，必须据实报告样本结果。

| 编号 | 场景与通过条件 |
|---|---|
| A01 | 使用同题标准卷及有真实手写答案的照片完成全链路；不是只用空白卷验证识别。 |
| A02 | 多张照片形成一个学生的一次提交，乱序能匹配；倒置页自动转正。 |
| A03 | 模糊、缺边、不同卷或对齐失败有具体提示，不硬批；单张可替换。 |
| A04 | 少一页能报出缺失的标准物理页及可用印刷页说明，不把缺页判零分。 |
| A05 | 一题跨栏、跨页或跨小问空白，作答能对应且按序保留，不串邻题。 |
| A06 | 客观题、公式计算和证明题有识别数据及评分结果；看不清与未作答能区别。 |
| A07 | 调用记录证明正常首轮只有一次全卷评分请求；请求中无图片附件、取图工具或可变相取图的输入。 |
| A08 | 有评分标准按其执行；无评分标准仍可给分且说明依据，不强制老师先确认生成标准。 |
| A09 | 作图题/作图小问待人工，未调用多模态评分；带印刷图但条件足够的文字题不一律排除。 |
| A10 | 题干图片语义不足时提示，不假装文字模型看到了图片。 |
| A11 | 漏题、重复题、超满分、负分、缺理由的构造结果都能被发现；原始结果可追溯。 |
| A12 | 总分由程序求和，父子题不重复计分；有未评分部分时明确显示未完成。 |
| A13 | 老师改分后机器分、人工分、原因均保留；补拍后旧结果能追溯且不混入新总分。 |
| A14 | 查看原照片/校正图/识别文字/逐题理由及卷面标记，位置对应正确。 |
| A15 | 显示识别与评分各自耗时、费用、重试和未知项；刷新后能找回。 |
| A16 | 标准卷后续修改不改变本次批阅依据；正常快速录入流程仍可使用。 |

## 10. 开发前验证项与后续决策

- 手写识别服务、模型、确切接口、公式和坐标输出质量及计价尚未选定；已有 MinerU 印刷识别不能算手写能力已验证。
- 样本未证明手写识别效果，需用真实作答测出漏字、公式错误、漏步骤和题目错配。
- 配准质量阈值、整卷请求预算、超时和重试策略由开发实测确定，不提前承诺速度或价格。
- 标准卷图形语义不完整的题，需要先补足可验证的文本条件或留待人工；不能用评分模型取图绕过本期文字评分边界。
- 小问分值不足时的保守处理、结果布局和批注细度按工程默认实现；若后续调整，单独记录产品决策。

这些验证项影响实现与可验收性，不表示需要重新讨论已确认的主流程，也不授权开通新的付费服务。
