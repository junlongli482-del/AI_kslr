# 快速录入｜MVP需求文档

版本：v0.1｜日期：2026-10-15｜状态：可供开发使用的工作基线，尚未实现或验收。

配套文档：[快速录入-MVP开发文档](快速录入-MVP开发文档.md)。

## 1. 目标与决策依据

把已有试卷、教辅或题目文件，经 MinerU 识别、数据整理及 AI 编排，变成可编辑的题目、试卷及原卷区域数据。用户主要操作是上传资料和最终审核修改，不逐题重新录入。

第一版重点验证真实识别与加工效果：原卷切题、跨页跨栏关联、公式与图片还原、答案解析匹配、属性标签生成、前端对照编辑以及题库和试卷库保存。原始教辅已印刷，必须适配原卷，不要求重新排版、增加定位点或重新打印。

决策依据优先采用当前会话。用户已确认技术路线可行，并授权工程自行选择可调整的默认细节。外部《快速录入-需求与效果定义》仅为参考，其“必须重排标准卷面”、历史技术状态、阈值和全部功能范围不自动沿用。

本文区分三种口径：

- **已确认要求**：用户明确描述的目标、功能及边界。
- **本版默认**：用户授权自主确定的实施规则，可根据真实样本调整。
- **后续范围**：预留结构，不以已实现功能或本版验收承诺呈现。

## 2. 范围与非目标

### 2.1 已确认要求

1. 支持 PDF、图片、Word 输入；以 MinerU 密钥接口识别，前期 PDF 和图片优先，Word 转 PDF 后走统一流程。
2. 利用 Markdown、图片及 JSON 中有效的坐标和布局数据，不把完整冗长 JSON 无差别发送给模型。
3. AI 自动判断题目结构、题目区域、跨页跨栏关联并输出机器可解析 JSON。
4. AI 生成或匹配题目属性、标签、答案和解析；允许后续增加属性和升级 AI 处理流程。
5. 答案可与题目分文件上传、集中在同文件末尾、紧跟每道题，或混合出现；答案文件可以含无关内容及多份试卷答案。
6. 答案和解析不要求执行题目区域框选流程，但图片、公式、表格需保留并关联。
7. 是否由 AI 生成答案解析是可选项；关闭则不生成。
8. 前端渲染后可直接编辑，支持原卷对照、题框调整、可视化公式与 LaTeX 双模式编辑。
9. 形成题库、试卷库以及教辅原卷区域模板；原始与中间数据可追溯。
10. 没有知识点目录等基础数据时可以先跳过，不阻断核心链路。

### 2.2 本版默认范围

先交付本地可运行的单操作员验证工作台，以两份真实教辅 PDF 和共用答案 PDF 为首批样本。支持同任务多个题目文件和多个答案文件；一个文件包含多套卷时允许自动分组并人工修正。任务组不等于一张试卷。

交付上传与任务页、审核工作台、题库列表及题目详情、试卷库列表及试卷详情。显示真实处理状态，保存真实数据；模拟数据只能用于开发，不能代替最终联调。

### 2.3 后续范围

本版不实现学生扫描件配准、身份识别、实际 AI 批阅、完整组卷、标准卷面重排、学校共享及运营协作审核。保留接入现有平台的业务边界，但不在本次验证中重建上一阶段全部账号与学校管理功能。

保存原卷坐标仅表示建立模板，不代表扫描或照片批阅已经可用。重要程度的完整排序算法、跨库语义去重、授权工作流和完整知识点资产建设不作为本版阻断项。

## 3. 三种录入结果

| 模式 | 题库 | 试卷库 | 原卷区域模板 |
|---|---|---|---|
| 教辅卷／作业录入 | 保存题目 | 保存试卷及顺序、题组、分值 | 必须保存，供后续原卷批阅接入 |
| 普通资料：仅题目 | 保存题目 | 不生成试卷库记录 | 不启用扫描模板 |
| 普通资料：整卷 | 保存题目 | 保存试卷 | 不启用扫描模板 |

三种模式共用识别与结构化能力。普通模式仍可保存来源坐标供对照，但不能因此标记为“支持扫描批阅”。

## 4. 输入与任务流程

### 4.1 上传

用户选择录入模式，上传题目文件，可选上传答案解析文件，并可勾选“对缺失的答案和解析使用 AI 生成”，默认不勾选。原资料已有内容正常提取，不受生成开关影响。

允许 PDF、JPG、JPEG、PNG、DOCX、DOC；旧版 DOC 转换能力取决于转换组件，失败时明确建议另存 DOCX 或 PDF，不假装成功。图片可以是一页或多页拍照，用户可调整顺序。不同文件各自保留身份、页序和用途。

完整多页 PDF 整体提交给 MinerU，不因有四页就拆成四次请求。页面渲染用于前端与切图，属于本地展示处理，不等同于拆分远程识别。服务硬限制导致拆分时需显式记录并恢复全局页码与关联关系。

上传时学科、年级、教材等尽量由文件和上下文自动推断，可集中修正；未知值留待审核，不要求用户逐项先填完。

### 4.2 状态与失败恢复

流程：已上传 → 格式准备 → MinerU 识别 → 数据整理 → AI 编排 → 系统校验 → 待审核 → 审核入库。

阶段失败显示实际原因、已保留结果和重试入口。从可复用的阶段恢复，避免只因标签失败就重新支付整份 OCR 成本。用户可先保存不完整草稿。

刷新页面或重启服务后，已持久化任务可查询和恢复；不能把浏览器持续打开作为处理完成的条件。

## 5. 题目识别与区域切割

### 5.1 题目结构

识别卷头、题组、大题、题号、题干、选项、小问、公式、图片、表格、分值及答案解析。页眉、页脚、密封线、印刷页码、定位标记不能误作题干。

大题保留父题与小问层级，不把小问无条件拆成彼此独立的题库题目。共用题干、共用材料和共用插图可被小问引用。后续支持调整父子关系。

### 5.2 多区域题

一道题允许对应多个矩形区域，分别记录源文件、PDF物理页、位置和拼接顺序。跨栏、跨页题保留原位置，同时按阅读顺序呈现为同一道完整题。

不能把跨栏题的所有块简单包进一个巨大矩形，导致相邻题混入。输出必须同时支持查看各区域原图及按序组合预览。

### 5.3 坐标与页面语义

区分 PDF 物理页与印刷页码。样本中一个横向 PDF 页呈现左右两个印刷页面，不能把印刷页码直接当成文件页索引。切图始终按物理页坐标执行。

题目结构化关联内容块；切割结果必须经过真实页面叠框和裁图验证，不把“模型返回了坐标”当成切割正确。

### 5.4 内容区域与作答区域

本版默认分别记录题目内容区域和作答区域。内容区域覆盖题干、选项与必要图表；主观题作答区域还需覆盖答题留白。客观题的题库内容与未来答题卡映射分开保存。

首版主要验收题目识别与切割，作答区域提供候选和人工调整，不声称已完成学生笔迹识别或答题卡配准。无法确定的区域明确标为待审核。

## 6. 内容与图片布局

题目以可编辑文本和结构化内容为主，数学公式以 LaTeX 保存。插图作为独立资产引用，表格尽量保留结构，无法可靠转换时保留图片并标注待确认。

保留图片的原始像素尺寸、原卷位置、相对展示尺寸、顺序、同行分组及同行占比。多张图、A/B/C/D 图形选项、图1/图2等不能统一渲染成一图一行，也不能因原始图像分辨率不同而破坏比例。

允许布局接近原稿而非逐像素复刻；题意、图片对应关系、顺序、公式和可编辑性优先。缺图、图片引用失效和公式渲染失败必须在审核中可见。

## 7. 答案与解析

### 7.1 匹配原则

答案文件先识别成答案条目和材料分组，再匹配试卷及题目。结合试卷名、章节、题组、题号、小问、题意和答案类型判断，不仅按题号匹配。

同一答案文件可以服务多个题目文件；无关章节、其他试卷答案、无法确定的条目保留为“未采用／待匹配”，不强塞给当前题目。展示匹配来源，允许人工重选、解除和修改。

答案、解析分别记录完整性。原资料“略”“图略”“理由略”按原样保存，并标明缺少详细内容，不能标为完整解析或凭空视作已提取图片。

### 7.2 生成与来源

关闭生成时不补写缺失答案解析。开启时默认仅补缺，已有答案不自动覆盖；存在冲突时人工决定。没有分值依据时不编造正式步骤分。

内容来源区分原卷提取、答案文件提取、AI生成、人工修改；人工确认状态单独记录。AI推断、候选匹配不能显示为用户已审核。

答案中的图片保留为独立资产，关联到对应答案或解析，显示必要的布局；不要求给答案文件建立批阅区域模板。

## 8. 属性、标签与扩展

### 8.1 属性范围

| 分类 | 属性及用途 |
|---|---|
| 归属与来源 | 资源归属、来源文件、教辅名称、原卷题号与页码、来源备注 |
| 教学分类 | 学段、年级、学科、教材版本、具体章节点、知识点 |
| 题目特征 | 题型、难度、能力维度、作答形式、情景与背景 |
| 评分 | 试卷分值、答案、解析、评分标准与步骤分 |
| 来源筛选 | 年份、地区、真题／模拟题／练习题等来源类型 |
| 生命周期 | 版本、状态、人工审核记录 |
| 使用管理 | 去重状态、授权状态和备注 |
| 计算与扩展 | 重要程度、排序依据、自定义标签、算法生成标签 |

试卷中的分值优先属于题目在该卷的引用，不因同一道题在不同试卷使用不同分值而互相覆盖。题目可保留推荐分值。

### 8.2 本版默认

难度采用五级，允许未知；知识点可多个，不强制每题必须有主要知识点；题型、能力维度、作答形式等采用可配置目录。客观／主观属于判分类别，作图属于作答形式，可同时存在，不强制互斥。

知识点有正式目录时，采用上层范围筛选再下钻具体目录；模型返回目录 ID，不能自行新增正式知识点。教材章节根据知识点、教材版本及映射目录得到，可多对多。教材未知时不随意指定章节。

未提供知识点目录或映射时，字段状态为“未配置”，不伪造正式知识点；可以保留 AI 的描述性候选，但明确未绑定。用户不必为缺少目录而停止验证主链路。

来源归属与授权由上传上下文或人工确认，AI只能提取线索，不能推定已授权。去重首版做文件哈希及规范化内容哈希提示，不自动合并或删除题目。

“重要程度与地位”预留计算结果、因素及规则版本：年份、地区、真题／模拟题、来源质量、知识点重要性等。数据不足时不计算，不用随意分数代替真实排序。

### 8.3 扩展约束

标签定义支持稳定标识、名称、值类型、适用范围、选项目录、是否多选、赋值来源及版本。新增来源教辅、平台精选或计算标签时不推翻题目核心结构。

AI使用当次启用的属性定义和候选目录，保留协议、目录、提示词和模型版本。新标签可以只对新任务启用；旧题后台重标注采用独立任务，不能静默覆盖人工结果。

## 9. 前端审核与编辑

### 9.1 页面构成

默认三部分：原卷区域、题目导航、渲染后的题目编辑与属性面板。比例可调整，属性面板可折叠。普通使用者不编辑 JSON。

- 原卷可缩放、平移、切页并显示题框；点击题目定位原卷，点击题框定位题目。
- 编辑区显示完整题干、选项、小问、图片、表格、公式、答案与解析；修改后可立即预览。
- 支持新增漏题、删除误识别题、合并跨区题、拆分串题、调整顺序和修正父子关系。
- 题框可新增、拖动、缩放、删除及调整所属题目；跨页区域按顺序保存。
- 答案显示来源分组、原文及候选匹配；可定位源答案页供对照。
- 属性通过搜索、多选、下拉和文本控件编辑；未知或未配置不伪装成识别成功。

### 9.2 公式

公式正常状态渲染为数学表达式，点击进入可视化公式编辑器，通过符号、分式、根号、上下标、矩阵等编辑；可切换 LaTeX 源码。存储以 LaTeX 为主，保留原文。

编辑器不支持的语法保留源码并显示预览或明确错误，不因切换模式而丢失。首版用真实数学样本验证公式往返编辑。

### 9.3 草稿与入库

自动保存采用版本校验，显示保存中、已保存、失败重试，刷新后恢复。AI重跑生成新处理结果供比较，不直接覆盖人工编辑。

允许不完整结果保存草稿；完成审核入库需无结构性错误，已审核题目内容和区域关联。缺答案时允许作为待完善资源保存，禁止标为可直接批阅。生成开关关闭不构成强制补答案要求。

题库与试卷库均能打开已保存结果并再次渲染。原卷模板标注“已审核／待审核”；实际扫描配准能力单独标注为尚未接入。

## 10. 自检与质量说明

系统检查协议结构、必需引用、资源存在、页码、坐标越界、题目重复、异常题号、分值与小问结构、答案冲突和目录 ID 等。

题号不连续、分值不等于满分、缺答案等是可解释提示，需结合节选、重号及未标分情况判断；不能无条件阻断正常节选资料。无有效题目、非法坐标、丢失关键资源或损坏结构阻断正式入库。

规则通过不代表识别正确。质量报告分别记录机器初稿质量和人工修正后质量，以及剩余错误和审核操作，不用人工修正后的效果冒充自动准确率。

## 11. 首批样本与验证策略

### 11.1 已检查样本

| 文件 | 本地只读检查结果 |
|---|---|
| 26秋金版 数学 九年级上册（人教版）试卷_1-4.pdf | 4个物理页；每页约1122.42×824.82 PDF点；首屏为期中综合测试 |
| 26秋金版 数学 九年级上册（人教版）试卷_5-8.pdf | 4个物理页；尺寸同上；首屏为期末综合测试 |
| 提取自26秋金版 数学 九年级上册（人教版）答案(1).pdf | 1个物理页；约569.73×824.82 PDF点；含其他章节及期中、期末答案 |

检查方式：本地读取页数和页面尺寸，渲染并查看三个文件的第一页；基础文本提取未取得文本，不能依赖 PDF 文本层。尚未调用 MinerU 或 GPT，尚未检查全部页面。

首屏确认的测试点包括：期中第6题跨左右栏；期末第1题有同行四个图形选项；第7题有同行图1与图2；共用答案中不同试卷题号重复，且有“略／图略”。后续需遍历完整文件建立基准清单，不凭首屏推断总题数。

### 11.2 验证方式

先把两份题目与共用答案放在同一任务中，再分别录入并引用同一答案文件，验证分组和匹配。补充同文件集中答案、随题答案及混合答案的测试材料；若由现有文件组合构造，必须标为衍生测试，不当作真实新样本。

图片和 Word 功能用真实文件或注明来源的衍生材料验证；未获得手机照片前，不声称验证了拍照畸变或低清识别。
