# 03 · 接口契约

- 基址：`http://127.0.0.1:1002/api`（Web 端经 Vite `/api` 代理，生产经 Nginx）。
- 全部 JSON；无鉴权（本地单操作员），生产由 Nginx Basic Auth 保护。
- 错误统一 `{"type":"...","message":"...","code":"..."}`。

## 1. 健康检查

```
GET /api/health
→ {"status":"ok","mode":"local-single-operator","database":"postgresql"}
```

## 2. 任务

### 列表

```
GET /api/quick-entry/tasks
→ [{ "id":"3f9b...", "title":"…", "mode":"textbook", "status":"ready",
     "stage":"等待审核", "message":"", "revision":3, "folder_id":"…",
     "created_at":"2026-10-24T12:00:00Z", "cost": { "total":0.0123, ... } }]
```

### 详情

```
GET /api/quick-entry/tasks/{id}
```

### 新建

```
POST /api/quick-entry/tasks
{"title":"26金版数学 选择性必修2 样卷_1-2","mode":"textbook","generate_answers":false,"channel_policy":"low_first"}
→ {"id":"3f9b..."}
```

`mode`：`textbook`（教辅/作业）| `questions`（只有题）| `paper`（整卷）。

### 上传文件

```
POST /api/quick-entry/tasks/{id}/files   (multipart)
files=@题目.pdf ; role=question
files=@答案.pdf ; role=answer
→ {"files":[...]}
```

`role`：`question` | `answer` | `mixed`。一份文件内含答案时用 `mixed`。

### 启动 / 重试

```
POST /api/quick-entry/tasks/{id}/start
POST /api/quick-entry/tasks/{id}/retry
→ 任务对象
```

### 删除

```
DELETE /api/quick-entry/tasks/{id}
```

`committed` 状态拒绝删除（409）。

## 3. 审核

### 读取草稿

```
GET /api/quick-entry/tasks/{id}/review
→ {"result": {...}, "revision": 3}
```

`result` 结构见 [02 文档第 5 节](02-数据模型与数据库.md)。

### 保存草稿（乐观锁）

```
PUT /api/quick-entry/tasks/{id}/review
{"expected_revision":3,"result":{...}}
→ {"revision":4}
```

`expected_revision` 与当前不一致返回 409，前端提示刷新。

### 规则校验

```
POST /api/quick-entry/tasks/{id}/validate
{"result":{...}}        // body 可省略，省略则校验当前草稿
→ {"issues":[{"level":"error","message":"第 5 题缺少答案"}], "ok":false}
```

### 单题重生成评分标准

```
POST /api/quick-entry/tasks/{id}/question-rubric
{"question_id":"q3","subquestion_id":null}
```

### 区域识别（框选图片转文字）

```
POST /api/quick-entry/tasks/{id}/region-recognize
{"document_id":"d1","page_index":0,"bbox":[0.1,0.2,0.5,0.4],"kind":"stem"}
→ {"text":"…","formula":[...]}
```

### 审核入库

```
POST /api/quick-entry/tasks/{id}/commit
{"revision":4}
→ {"paper_id":"...","questions":24}
```

## 4. 资产

```
GET /api/assets?key=tasks/{taskId}/{doc}/raw/images/page_0_image_3.jpg
→ 二进制（pdf/png/jpg/jpeg/webp）
```

非法 key 或路径越界返回 404；不存在的文件 404。

## 5. 题库 / 试卷库

```
GET /api/questionbank/questions?query=数列
GET /api/questionbank/questions/{id}
GET /api/paperbank/papers
GET /api/paperbank/papers/{id}          // 含 questions 与 templates
```

返回的 `content` 是 JSON 字符串还是对象由 `decoded()` 决定：接口会 `parse` 成对象。

## 6. 导出（给批阅/题库）

```
GET /api/export/papers                   // 全部已提交试卷摘要
GET /api/export/papers/{id}              // 单卷完整
GET /api/export/questions/{id}           // 单题
```

单卷导出示例（截断）：

```jsonc
{
  "schema_version": "p1-export-v1",
  "exported_at": "2026-10-24T12:00:00Z",
  "folder_id": "f1",
  "folder_path": ["教辅","金版学案","2026金榜学案高中数学必修一（人教版）"],
  "paper": { "id":"p1","title":"…","attributes":{...} },
  "questions": [{
    "id":"q1","sort_order":1,"score":5,
    "content": {
      "id":"q1","number":"9-11","stem":"…","options":[...],"answer":"…","analysis":"…",
      "subquestions":[{"subquestion_id":"q1-sub-1","number":"(1)","stem":"…"}],
      "attributes":{"question_type":"综合题","knowledge_points":[{"id":"4700","name":"…"}],"difficulty":0.42}
    }
  }],
  "template": {
    "blanks":[{
      "blank_id":"br-...-0-8","question_id":"q1","sub_node_id":"q1-sub-1",
      "question_number":"9-11","subquestion_number":"(1)",
      "blank_label":"9-11-1","index_in_question":1,"index_in_node":1,
      "binder":"auto","bound":true,"bbox":[0.12,0.44,0.31,0.47]
    }]
  },
  "question_regions": [...],
  "template_documents": [...],
  "template_review_status": "confirmed",
  "scan_capability": "not_integrated",
  "assets": [...]
}
```

批阅侧使用建议：

- 按 `blank_label` 展示/匹配（题组不会再混淆）；
- 题目答案优先取 `content.answer`，小题取 `subquestions[].answer`；
- 评分标准在 `content.scoring`（如有）；
- 图片用 `assets[]` 或题干中的 `/api/assets?key=`。

## 7. 文件夹

```
GET    /api/folders                          // 扁平列表：id,parent_id,name,sort_order
POST   /api/folders                          // {name,parent_id?}
PUT    /api/folders/{id}                     // {name?,parent_id?}  改名/移动，防环
DELETE /api/folders/{id}                     // 仅空目录，非空 409
PUT    /api/quick-entry/tasks/{id}/folder    // {folder_id}
```

前端用扁平列表自行建树（`parent_id` 为 null 是根）。

## 8. 提示词（AI 服务，经 `/prompt-api` 代理）

```
GET    /prompt-api/prompts                   // 27 个 key 的列表
GET    /prompt-api/prompts/{key}             // 当前内容 + 历史摘要
PUT    /prompt-api/prompts/{key}             // {content}
POST   /prompt-api/prompts/{key}/rollback    // {revision}
DELETE /prompt-api/prompts/{key}             // 恢复默认
```

key：`structure`、`columns`、`answers`、`match`、`blank-match`、`rubrics`、`tagging:{stage}-{subject}`。
