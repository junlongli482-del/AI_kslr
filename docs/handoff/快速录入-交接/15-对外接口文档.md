# 15 · 对外接口文档（题库 / 批阅对接）

> 版本 2026-10-26。面向题库、批阅、学情三个下游。
> 配套文件：`export-sample.json`（真实导出样例，已裁剪）、`abilities.csv`（能力与认知层级码表）。

## 1. 通用约定

| 项 | 说明 |
|---|---|
| Base URL | 开发 `http://127.0.0.1:1002/api`；生产经 nginx `http://<host>:2001/api` |
| 认证 | 生产由 nginx Basic Auth 提供；开发环境无认证 |
| 编码 | UTF-8，`application/json` |
| 时间 | ISO-8601 带时区，如 `2026-10-26T00:41:47.959+08:00` |
| 错误 | 4xx/5xx + `{ "message": "..." }`；业务错误用 409（状态不符）、400（参数非法） |
| 图片 | 接口只返回 `key`，字节通过 `GET /assets?key=` 读取 |

## 2. 接口清单

### 2.1 导出（下游主要用这三个）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/export/papers` | 已入库试卷列表 |
| GET | `/export/papers/{paperId}` | 单卷完整导出 |
| GET | `/export/questions/{questionId}` | 单题导出 |

### 2.2 题库 / 试卷库浏览

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/questionbank/questions?query=&limit=` | 题库题目列表（最新版本） |
| GET | `/questionbank/questions/{id}` | 单题详情 |
| GET | `/paperbank/papers` | 试卷库列表 |
| GET | `/paperbank/papers/{id}` | 单卷详情 |

### 2.3 资产与目录

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/assets?key=` | 读取图片/PDF 字节 |
| GET | `/folders` | 分组树 |
| GET | `/catalogs` | 字典状态（当前返回 `unconfigured`） |
| GET | `/health` | 健康检查 |

### 2.4 录入端（下游一般不用）

任务增删查、文件上传、启动/重跑、审核草稿读写、规则校验、入库、成本查询等，
详见 `03-接口契约.md`。

## 4. 导出：单卷（核心接口）

```
GET /export/papers/{paperId}
```

未入库返回 409；不存在返回 404。

### 4.1 顶层结构

| 字段 | 类型 | 说明 |
|---|---|---|
| `schema_version` | string | `p1-export-v1`，只增字段不删字段 |
| `exported_at` | string | 导出时间 |
| `task_id` / `task_status` | string | 来源任务 / 恒为 `committed` |
| `folder_id` / `folder_path` | string / array | 分组信息，`folder_path` 是从根到当前的名字数组 |
| `question_count` | int | 实际题目数 |
| `computed_total_score` | number | 题目分值合计 |
| `question_groups` | array | 按题型分节：`[{name,count,score,question_ids}]` |
| `paper` | object | 试卷（见 4.2） |
| `questions` | array | 题目，每项 `{id, sort_order, score, content}`（见 4.3） |
| `template` | object | 原卷模板：`blanks / annotations / student_zones / bracket_status` |
| `question_regions` | array | 题目在原卷上的区域 |
| `template_documents` | array | 页图索引 |
| `assets` | array | 图片 key 列表 |
| `template_review_status` / `scan_capability` | string | 模板审核状态 |

字段说明：

| 字段 | 取值 |
|---|---|
| `paper_type` | 26 值之一（含「其他」） |
| `attributes.stage` | 小学 / 初中 / 高中 |

## 5. 字段字典

### 5.1 题目标签

| 字段 | 含义 | 取值 |
|---|---|---|
| `attributes.question_type` | 题型名 | 如 单选题、填空题 |
| `attributes.question_type_id` | 题型码 | 如 `qt3401` |
| `attributes.question_type_sub_raw` | 学科子形态原值 | 字典口径，仅供留痕 |
| `attributes.sub_type` | **结构子形态** | `single` 单题 / `group` 题组（小题 ≥2） |
| `attributes.knowledge_points` | 知识点 | 最多 5 个，带 role |
| `attributes.difficulty` | **预估得分率** | 0.00–1.00，**越大越容易** |
| `attributes.difficulty_band` | 难度档 | 容易 ≥0.80 / 适中 0.50–0.80 / 困难 <0.50 |
| `attributes.ability_primary` | 主能力码 | 见 `abilities.csv` |
| `attributes.ability_secondary` | 次能力码 | 可空 |
| `attributes.cognitive_level` | 认知层级 | `C1` 识记 / `C2` 理解 / `C3` 应用 / `C4` 分析 |
| `grading_method` | 批阅方式 | `program` 程序批阅 / `ai` 智能批阅 |

### 5.2 出处快照（题目上直接带，不必 join 试卷）

`year`、`semester`、`region`、`paper_type`、`exam_stage`、`exam_nature`、`grade`、`stage`、`subject`、
`source_name`、`source_nature`、`school_publisher`

## 6. 括号（填空）归属

`template.blanks[]` 每项在导出时补齐：

| 字段 | 含义 | 例 |
|---|---|---|
| `question_number` | 落在哪一题（题组取小题自己的题号） | `7` |
| `paper_question_number` | 父题号（题组为区间） | `7` 或 `3-4` |
| `subquestion_number` | 落在哪一小问 | `(1)` |
| `blank_index` | 本题第几个空 | `1` |
| `blank_label` | 完整标签 | `7-1` |
| `bound` | 是否已归属 | `true/false` |

未归属（`bound=false`）的空白值为空并进 issues，由人工处理。

## 7. 资产读取

```
GET /assets?key=tasks/{taskId}/{docId}/origin/page-0.png
```

返回图片字节。`questions[].regions[].crop_url`、`image_layout` 的键、`assets[]` 里的 key 都可用这个接口取。

## 8. 对接建议

| 场景 | 用什么 |
|---|---|
| 题库入库 | 全量 content + `regions` + `blanks` + `tables` + `scoring` + `assets` |
| 指纹与折叠 | **由题库侧自行实现**，录入侧不提供 |
| 批阅路由 | `grading_method`：`program` 走机读，`ai` 走模型 + 人工兜底 |
| 批阅定位 | `regions`（题框）、`blanks`（填空锚点）、`template.student_zones` |
| 学情诊断 | `knowledge_points` × `difficulty` × `ability_primary` × `cognitive_level` |
| 筛选 | 出处快照（年份/地区/卷型/性质/来源/年级/学期） |
| 组卷 | `paper_type`、`exam_nature`、`question_groups`、题型分布 |

## 9. 变更记录

### 2026-10-26（v2）

**新增**

- 题目：`ability_primary` / `ability_secondary` / `cognitive_level`、`sub_type`
- 试卷：`manual.quality_level` / `quality_score` / `quality_missing`、`manual.tags`
- 导出：`question_count`、`computed_total_score`、`question_groups`
- 填空：`question_number` / `paper_question_number` / `subquestion_number` / `blank_index` / `blank_label`

**修正**

- `blank_label` 之前恒为空（题号取错了层级），现已修复

**废弃**

- `textbook_volume`、`textbook_version`、`publisher_name`、`publisher_series`

**说明**

- 难度统一为「预估得分率 0–1」，不再输出 1–5 档位；档位由数值派生
- 批阅方式统一为 `program` / `ai`，不再出现 `auto` / `manual`
