# 07 · 测试与验收

## 1. 自动化测试

### AI（pytest）

```bat
.venv\Scripts\python.exe -m pytest apps\ai\tests -q
```

覆盖：栏数判定、短块 ID、题框几何、图片分组、A4 双栏、学生用书 sections/bands、填空令牌、打标校验等（当前 70+ 条）。

改 `core.py` / `media.py` 必须跑；新增分支要补用例。

```bat
node apps\web\node_modules\vue-tsc\bin\vue-tsc.js --noEmit -p apps\web\tsconfig.json
```

cd apps\api

没有完善单测；改 Controller/Service 后至少编译 + 真实接口调用。

## 2. 真实卷回归（每次改识别/提示词必做）

1. 清空开发数据；
2. 新建一份**有题组**的卷（地理/数学最典型）；
3. 检查：
   - 题框不漏、不重叠；
   - 题组的小题齐全、`subquestion_id` 稳定；
   - 括号在审核页显示 `9-1` / `9-2`，能手动归属；
   - 填空令牌与答案对应；
   - 打标：题型/子形态/知识点/难度写入，`tag_status=ok`；
   - 审核入库成功；
4. 导出 `/export/papers/{id}`，核对 `blank_label`、`folder_path`、`knowledge_points`。

## 3. 打标验收线（来自数据方规格）

| 维度 | 指标 |
|---|---|
| 题型 Top-1 | ≥ 90% |
| 子形态（限有子形态样本） | ≥ 70% |
| 知识点 F1（按 id） | ≥ 0.80 |
| 难度 MAE | ≤ 0.12 |
| 校验通过率 | ≥ 98% |

评测方法：人工标 50–100 题作金标，逐题比对；知识点按集合 F1；难度用绝对误差。

## 4. 缓存与成本监控

- `llm/*.json` 里有 `usage.cached_tokens`；
- 同科连续跑，缓存命中占比应 ≥90%；
- 低于 90% 排查：前缀被改、任务交错、并发导致前缀切换；
- 单卷成本 = 新算 input×单价 + 缓存读×单价 + output×单价。

## 6. 验收话术

不要用“应该可以”。给：

1. 改了什么文件；
2. 跑了什么命令、结果如何；
3. 哪一项没验证、为什么；
4. 用户需要做什么。
