# 11 · 业务术语表

给不熟悉教辅/试卷业务的开发。

| 术语 | 含义 | 在系统里的体现 |
|---|---|---|
| 教辅 | 配合教材的练习册/试卷集，如《金版学案》《金榜学案》 | 文件夹树：教辅 → 书名 → 课时/试卷 |
| 同步 | 与教材章节进度一致的练习 | `paper_type`、分组路径 |
| 课时作业 | 每节课后的作业页 | 通常一份 PDF 一个课时 |
| 整卷 | 完整考试卷（期中/期末/模拟） | `mode=paper` |
| 题组 | 一段材料下带多个小题，共享题干，如 3-4 题 | 一个 `question` + `subquestions[]`，题号 `3-4` |
| 小题 / 小问 | 题组里的 (1)(2)(3) | `subquestions[].subquestion_id`，稳定 ID |
| 题干 | 题目主体文字（含材料、图片） | `stem` |
| 选项 | 选择题 A/B/C/D | `options[]` |
| 答案 | 标准答案 | `answer`，小题各自有 |
| 解析 | 解题过程 | `analysis` |
| 评分标准 | 主观题分步给分细则 | `scoring` / rubric |
| 题框 | 题目在原卷上的矩形区域 | `regions[].bbox`（0–1 归一化） |
| 区域图 | 从题框裁出的图片 | `image_layout` / `assets` |
| 括号 | 填空题/作答处的 `（　　）` | `template.blanks[]`，带 `blank_label` |
| 填空 | 题干中的空格 | `{{blank}}` / `{{blank:n}}`，答案在 `blanks[]` |
| 学生用书 | 学生版教材/练习（答案在教师版） | `mode=textbook`，需要 `sections/bands` 限定范围 |
| 节 | 「第X节」标题 | `paper.sections[]`，范围到下一节为止 |
| 板块 | 「重点探究」「典例剖析」等横幅 | `paper.bands[]`，只影响排序，不切范围 |
| 栏 | 页面分栏（1/2/3 栏） | `paper.columns`、`column_conflict` |
| 栏数冲突 | AI 判定与几何判定不一致 | 审核页「按 AI / 按几何」 |
| 知识点 | 题目考查的学科知识点（树上的节点） | `attributes.knowledge_points[]`（id/name） |
| 知识点树 | 学科知识点层级 | `tagging/knowledge/*.json` |
| 题型 | 单选题/综合题/现代文阅读等 | `attributes.question_type(_id)` |
| 子形态 | 题型的细分，如「4个选项」 | `attributes.question_type_sub` |
| 难度 | 0–1，越大越难 | `attributes.difficulty` |
| 打标 | AI 一次给出题型/子形态/知识点/难度 | `assign_question_types` |
| 前缀 | 每个学段学科固定的 system 提示词 | `tagging/prompts/prefix-*.txt` |
| 章节映射 | 知识点 → 某教材版本的章节位置 | 下游用 `kp_position` 现算，本系统不存 |
| 入库 | 审核通过后写入题库/试卷库 | `commit` → `question_revision` / `paper_revision` |
| 试卷库 | 已入库的整卷 | `paperbank` |
| 题库 | 已入库的题目 | `questionbank` |
| 草稿 | 审核中的结果，可反复保存 | `qe_task.review` + `revision` |
| 恢复处理 | 失败/中断任务从断点重试 | `/retry`，复用缓存 |
| 成本 | 单任务模型调用费用 | `cost` 接口与页面 |
