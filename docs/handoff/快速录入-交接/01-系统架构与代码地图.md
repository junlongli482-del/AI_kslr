# 01 · 系统架构与代码地图

## 1. 三端职责

| 端 | 技术 | 端口 | 职责 |
|---|---|---|---|
| Web | Vue 3 + Vite + Element Plus + Tiptap | 1001 | 上传、任务列表、审核、模板标注、提示词设置 |
| API | Spring Boot 3.5 + MyBatis + Flyway | 1002 | 任务持久化、状态机、审核草稿、入库、导出、文件夹 |
| AI | FastAPI + Pydantic | 1003 | MinerU 调度、结构化、答案匹配、打标、题框几何 |
| MinerU | 本地 `mineru-kit api-server` | 8020 | PDF/图片 → Markdown + 块坐标（可选云端） |

数据流：

```
上传文件 → qe_file
POST /quick-entry/tasks/{id}/start → 调用 AI /process
AI 逐阶段回调 /tasks/{id}/state（写 state.json）
Java 每 2.5s 轮询 AI /tasks/{id} → 更新 qe_task.status/stage
ready → 前端打开审核 → 保存草稿（review JSONB）→ commit → 题库/试卷库
```

## 3. 模块边界与改动指引

| 想改什么 | 改哪里 | 注意 |
|---|---|---|
| 题框位置/重叠 | `apps/ai/core.py` `question_span_regions`、`apps/ai/media.py` `page_cells` | 坐标 0–1，跨页要按页分行 |
| 分栏判断 | `core.py` `detect_document_columns` + `media.py` | AI 判栏在结构化之前 |
| 填空/答案 | `core.py` 结构化提示词 + `tagging` 无关 | 填空只由 AI 输出，无正则回填 |
| 打标（题型/知识点/难度） | `core.py` `assign_question_types`、`tagging/` | 前缀必须按文件原文，字节一致 |
| 提示词 | `apps/ai/prompts.py` + `data/settings/prompts.json` + 前端弹窗 | 不要改代码常量来调效果 |
| 任务状态/重试 | `TaskService.sync/start`、`main.py process` | 不要破坏事件流水 |
| 审核页交互 | `App.vue`、`SourceViewer.vue` | 保存走 `PUT /review`，注意 revision |
| 入库/导出 | `TaskService.commit/exportPaper` | 导出 schema 版本 `p1-export-v1` |
| 文件夹 | `FolderController.java` + App.vue 分组栏 | 删除仅空目录 |

## 4. 认证与并发

- 当前为 `local-single-operator`：无登录、无多用户数据隔离；生产用 Nginx Basic Auth 挡在门外。
- AI 并发：`/settings/concurrency`，0 表示无本地上限；本地 MinerU 自身 `--concurrency 2` 排队。
- 任务状态：`uploaded → queued → running → ready | failed | interrupted → committed`。

- MinerU 4.0（`mineru-kit api-server`，standard 档，模型 MinerU2.5-Pro）
