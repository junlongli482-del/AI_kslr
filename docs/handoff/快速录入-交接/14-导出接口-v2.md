# 14 · 导出接口（题库 / 批阅对接）v2

> 2026-10-26 更新。相对旧版**只增不删**，`schema_version` 仍为 `p1-export-v1`，
> 下游按字段名取用即可，不需要做版本分支。

## 1. 三个接口

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/api/export/papers` | 已入库试卷列表（不含题目） |
| GET | `/api/export/papers/{paperId}` | 单卷完整导出（试卷 + 全部题目 + 原卷模板 + 题框 + 素材） |
| GET | `/api/export/questions/{questionId}` | 单题导出（含 content 全量） |

只有 `status = committed` 的数据可导出，未入库的草稿不提供。

## 2. 单卷导出的顶层结构

```json
{
  "schema_version": "p1-export-v1",
  "exported_at": "2026-10-26T00:00:00Z",
  "task_id": "...",
  "task_status": "committed",
  "folder_id": "...",
  "folder_path": ["金榜学案", "必修二"],
  "paper": { ... },
  "questions": [ ... ],
  "template": { ... },
  "question_regions": [ ... ],
  "template_documents": [ ... ],
  "assets": [ ... ]
}
```

## 3. 试卷（paper）

### 身份

| 字段 | 含义 |
|---|---|
| `id` / `title` | 主键 / 卷名 |
| `paper_type` | 卷型，26 个值之一（含「其他」） |

### 属性（`paper.attributes`）

| 字段 | 含义 |
|---|---|
| `stage` / `subject` | 学段（小学/初中/高中）/ 学科（九个固定值） |
| `grade` | 年级，`g1`–`g12` |
| `semester` | 学期，`1` 秋季 / `2` 春季 |
| `year` | 年份（教辅取出版年，公开卷取考试年） |
| `region` | 地区，国标六位码（如 `440000`），教辅由来源默认值决定 |
| `exam_stage` | 考试阶段（一模/期中/高考…），按卷型性质分组 |
| `exam_nature` | 考试性质：真题/模拟/同步/专题/竞赛（由卷型派生） |
| `source_name` / `source_nature` | 来源名 / 性质（教辅、校本、公开、其他） |
| `publisher_name` / `publisher_series` | 品牌 / 系列（如 金榜学案 / 2026秋） |
| `school_publisher` | 学校或出版社 |
| `textbook_volume` / `textbook_version` | **已废弃，不再产出**，下游不要再读 |

### 卷面（`paper.exam`）

`duration_min`、`declared_total_score`、`declared_question_count`、`has_elective`、`has_listening`、`answers_at_end`

### 质量（`paper.manual`）

| 字段 | 含义 |
|---|---|
| `quality_level` | 精品 / 普通 / 待修（程序按完善度计算） |
| `quality_score` | 0–100 |
| `quality_missing` | 缺失项数组，如 `["解析","知识点标注"]` |

### 结构与分组

`sections`（章节横幅）、`bands`（板块横幅）、`lesson`（课时）、`source.columns`（每页栏数）、`issues`

## 4. 题目（questions[]）

### 内容

`id`、`paper_id`、`number`、`stem`、`options`、`subquestions`、`answer`、`analysis`、
`answer_source`、`analysis_source`、`answer_entry_id`、`corrections`、`issues`

- `number` 是卷面原样，题组为 `3-4` 这种区间；小题号在 `subquestions[].number`
- `subquestions[]` 含 `subquestion_id`、`number`、`stem`、`options`、`answer{value,analysis,scoring_criteria}`、`score`

### 标签（`attributes`）

| 字段 | 含义 |
|---|---|
| `question_type` / `question_type_id` | 题型名 / 题型码（如 单选题 / qt3401） |
| `question_type_sub_raw` | 学科子形态原值（如「2个小题」，字典口径，仅供留痕） |
| `sub_type` | **结构子形态**：`single` 单题 / `group` 题组（由小题数派生） |
| `knowledge_points` | `[{id,name,role}]`，最多 5 个 |
| `difficulty` | 0.00–1.00，**预估得分率，越大越容易** |
| `difficulty_band` | 容易 / 适中 / 困难，由数值派生 |
| `difficulty_reason` | 判定依据，一句话 |
| `ability_primary` | 主能力码，如 `GE-SEN-REG` |
| `ability_secondary` | 次能力码，可空 |
| `cognitive_level` | `C1` 识记 / `C2` 理解 / `C3` 应用 / `C4` 分析 |
| `ability_dimensions` | 兼容字段，= [primary, secondary] |
| `tag_status` | ok / tag_failed / manual |

### 批阅相关

| 字段 | 含义 |
|---|---|
| `grading_method` | `program` 程序批阅 / `ai` 智能批阅 |
| `scoring` | 评分标准 `{method, points[{pct,criterion}], deductions[], notes}`；程序可批的题没有采分点 |
| `regions` | 题框 `[{document_id,page_index,bbox,purpose,order,crop_url}]`，bbox 为 0–1 归一化 |

### 出处快照（从试卷继承，试卷改了会同步）

`year`、`semester`、`region`、`paper_type`、`exam_stage`、`exam_nature`、`grade`、`stage`、`subject`、
`publisher_name`、`publisher_series`、`source_name`、`source_nature`、`school_publisher`

题目侧这些字段**只读**，用于不 join 试卷就能按出处筛题。

### 结构与素材

`blanks`、`tables`（含 `structure_status`）、`image_layout`（按图片 URL 索引）、
`options_layout`、`regions`、`block_ids`、`asset_repairs`

## 5. 填空（blanks）的增强字段

导出时每个空都会补齐归属信息，**题组不再给区间号**：

| 字段 | 含义 | 例 |
|---|---|---|
| `question_number` | 落在哪一题（题组取小题自己的题号） | `4` |
| `paper_question_number` | 父题号（题组为区间，留痕用） | `3-4` |
| `subquestion_number` | 落在哪一小问 | `(1)` |
| `blank_index` | 本题第几个空 | `1` |
| `blank_label` | 完整标签 | `4-1` |

未归属（`bound=false`）导出空值并进 issues，由人工处理。

## 6. 原卷模板与素材

- `template`：`{blanks, annotations{brackets,question_numbers,qr,drop,score_box}, student_zones, bracket_status}`
- `question_regions`：题目在原卷上的区域
- `template_documents`：页图索引
- `assets`：图片键列表，实际字节通过 `/api/assets?key=` 读取

## 7. 代码级约定

- 所有坐标 `bbox` 为 0–1 归一化，顺序 `[x0,y0,x1,y1]`，配 `page_index`
- 填空令牌写在 `stem` 里（`{{blank}}` / `{{blank:n}}`），答案在 `blanks[].answer`
- 题组：一个 `question` + `subquestions[]`；单题：材料已在 `stem` 内，`subquestions = []`
- `fingerprint` / `fingerprint_version` / `foldable` **尚未启用**，字段保留，值为空；
  指纹算法按《题库系统-指纹与折叠规范 v0.1》由题库侧提供，录入侧只接入

## 8. 下游怎么用

| 场景 | 用哪些字段 |
|---|---|
| 题库入库 | 全部 content + `regions` + `blanks` + `tables` + `scoring` + `assets` |
| 按出处筛题 | 题目的出处快照（不 join 试卷） |
| 教辅识别 | `source_nature = 教辅` |
| 批阅路由 | `grading_method`：program 走机读，ai 走模型 + 人工 |
| 批阅定位 | `regions`、`blanks`、`template.student_zones` |
| 学情诊断 | `knowledge_points` × `difficulty` × `ability_primary` × `cognitive_level` |
| 组卷 | `paper_type`、`exam_nature`、`annual`、`region`、`grade`、题型分布 |
