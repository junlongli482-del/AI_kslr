- 本仓库只做 **快速录入（P1）**：资料 → 结构化题目 → 审核 → 入库 → 导出。
- **批阅（P3）与题库（P2）是下游**，不要改 `p2_bank` / `p3_grading` schema，也不要在这里实现批阅逻辑。
- 批阅侧依赖的数据：题目、答案、评分标准、题框坐标、知识点、难度、括号归属、文件夹路径，都通过导出接口提供。
