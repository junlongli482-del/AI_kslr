# 05 · 前端开发指南

技术栈：Vue 3 `<script setup>` + TypeScript + Vite + Element Plus + Tiptap + markdown-it + KaTeX/MathLive。

## 1. 页面结构（单页，`view` 切换）

`App.vue` 里 `view` 取值：

| view | 内容 |
|---|---|
| `tasks` | 任务列表、上传入口、分组栏、并发设置 |
| `progress` | 处理进度、阶段、失败原因、重试 |
| `review` | **核心**：原卷 + 题目列表 + 题目内容 + 属性 |
| `cost` | 单任务成本明细 |
| `student` | 学生信息区设置 |
| `questions` / `papers` | 题库 / 试卷库浏览 |

`navigate(next)` 负责切换；离开 `review` 会先 `saveDraft()`。

## 2. 审核页布局

```
顶部：返回 / 标题 / 已保存状态 / 试卷信息 / 保存草稿 / 重建题框 / 规则检查 / 审核入库
左：SourceViewer（原卷，题框层/块层/模板标注层，缩放，页码）
中：题目列表（全部 / 待核对），显示题号、分值、题型、区域数
右：题目内容（题干/选项/小问/答案/解析/填空答案/评分标准/原卷区域）
    属性标签（题型、子形态、知识点树、难度、地区、来源类型、能力维度等）
```

### 关键交互

- 题框拖拽/缩放 → 改 `question.regions[].bbox`；
- 「补框」在左图拖出新区域；
- 「重建全部题框」调用后端重算区域；
- 模板标注层：选中括号可「归属小题」下拉、删除；学生信息区可拖；
- 分栏冲突提示条：`按 AI（N 栏）` / `按几何（M 栏）`；
- 知识点：`el-tree-select` 多选、可搜索、可清空；
- 题型/子形态：下拉来自清单，不允许自由输入；
- 提示词按钮：打开设置弹窗（列表 + 编辑器 + 保存/恢复默认/历史回滚）。

## 3. 状态与数据流

- `task`：当前任务；`result`：`GET /review` 的 `result`；
- `selected`：当前题目（`result.questions` 的元素）；
- `revision`：草稿版本，保存时必须回传；
- `dirty/saveState`：改动后 1.2s 防抖自动保存；
- `watch(result, markDirty, {deep:true})`：任何字段改动都会触发保存；
- 所有修改直接改 `result` 里的对象（Vue 响应式），不要复制整棵树。

新增字段时：

1. `types.ts` 补类型；
2. `App.vue` 属性面板加控件；
3. 后端 Pydantic 模型（`core.py`）补字段，否则保存时被丢弃。

## 4. 渲染规则（`render.ts`）

- Markdown：`markdown-it` + KaTeX；
- 公式：行内 `$...$`，块级 `$$...$$`；编辑器用 Tiptap + MathLive；
- 填空：编辑态渲染 `____`，预览态 `span.blank`；
- 图片：`image_layout` 按几何分组，CSS `flex-wrap`，同页同排才并排；
- 题组：`subquestions` 依次渲染，小题题干可含图片；
- 表格：`tables` 直接渲染 HTML。

## 5. 组件接口

### SourceViewer

```
props: documents, questions, template, selected, page, zoom, answerDocumentId
emits: select, change, template-change
```

- `template-change`：模板（括号/学生区）被修改，需要保存草稿；
- 括号标签 `bracketText(a)`：已绑定小题显示小题号，否则 `题号-序号`；
- `reassignSub`：下拉修改 `sub_node_id`，同时更新 `blanks`。

### QuestionEditor

- 富文本 + 公式 + 图片插入；
- `v-model` 绑定题干/答案/解析字符串（含 markdown）。

## 6. 样式约定

- 主色 `#2f6b4f`，浅底 `#eef4f0`，边框 `--line`；
- 圆角 12–16px，卡片白底、细边框、无重阴影；
- 中文优先，字号 12–14px；表格紧凑；
- 新增样式写 `style.css`，组件内尽量少写 scoped。

## 7. 开发环境

```bat
scripts\dev.cmd web      :: 1001，HMR
```

- `/api` → 1002，`/prompt-api` → 1003（`vite.config.ts`）；
- 改 `vite.config.ts` 必须重启 Vite；
- 类型检查：`node node_modules/vue-tsc/bin/vue-tsc.js --noEmit -p apps/web/tsconfig.json`；
- 构建：`pnpm build`（生产镜像里构建）。

## 8. 常见改动示例

**加一个属性字段**

1. `types.ts` 的 `Question.attributes` 加字段；
2. 属性面板 `<label>` 加控件；
3. `core.py` 的 `Question` / `attributes` 模型允许该字段（Pydantic 默认 extra ignore，需显式加）。

**加一个接口**

1. `App.vue` 用 `api.get/post`；
2. 后端 `QuickEntryController` 加映射（记得类级 `/api` 已存在）。

**改题框颜色/标签**

- `SourceViewer.vue` 的 SVG 类；
- 样式在 `style.css` 的 `.template-layer` 段。
