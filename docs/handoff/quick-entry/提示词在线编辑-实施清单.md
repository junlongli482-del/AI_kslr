# 提示词在线编辑 · 实施清单（交接用）

目标：所有调用类型的 system 指令可在界面编辑、保存即生效、保留历史并可回滚。

## 一、锁定需求

1. 覆盖范围：结构化/版面、栏数判定、答案抽取、答案匹配、填空匹配、评分标准、答案生成、区域识别、打标（21 份，按学段+学科）。
2. 打标 key：`tagging:senior-geography`；其余：`structure`、`columns`、`answers`、`match`、`blank-match`、`rubrics`、`generate`、`region`。
3. 保存即生效，不重启；运行时优先覆盖，其次仓库默认。
4. 保留全部历史版本，支持查看/对比/回滚/恢复默认。
5. 试跑暂不做；打标前缀按学段学科独立管理。
6. 开发/生产数据各自隔离（覆盖记录存各自 data 目录或库）。

## 二、存储

推荐先用文件，避免数据库迁移：

```
data/settings/prompts.json
{
  "structure": {"current": {"content": "...", "sha1": "...", "revision": 3, "updated_at": "..."},
                 "history": [ ... ]},
  "tagging:senior-geography": {...}
}
```

- 读取：按 mtime 缓存，文件变了自动重载；
- 保存：追加当前内容到 history，revision+1；
- 回滚：把目标历史内容作为新 revision 保存（不删除后续历史）；
- 恢复默认：删除 current，回退到代码内默认。

## 三、代码改动

### AI（apps/ai）

1. 新增 `prompts.py`：
   - `PROMPT_DEFAULTS` 从 `core.py` 现有常量导入或搬迁；
   - `get_prompt(key, default)`：读 `QUICK_ENTRY_DATA_DIR/settings/prompts.json`，命中 current 则返回，否则返回 default；
   - `describe()`：返回所有 key、默认字符数、当前版本。
2. `core.py` / `main.py` 所有 `llm.json(name, PROMPT, ...)` 改为 `llm.json(name, get_prompt(key, PROMPT), ...)`：
   - structure、columns、columns-recheck、answers、match、blank-match、rubrics、generate、region。
3. 调用记录里写入 `prompt_revision` / `prompt_sha1`（llm calls 详情里加字段）。
4. 打标 `tagging_prefix()` 改为先查 `tagging:{slug}` 覆盖，再用文件默认。

### Java（apps/api）

新增接口（读写 data 目录下同一份 JSON，或通过 AI 服务代理）：

```
GET  /api/prompts                    列表：key、默认字符数、当前 revision/sha1/更新时间
GET  /api/prompts/{key}              当前内容 + 历史摘要
PUT  /api/prompts/{key}              保存新版本 {content}
POST /api/prompts/{key}/rollback     回滚 {revision}
DELETE /api/prompts/{key}            恢复默认
```

- 校验：内容非空；打标前缀需包含题型/知识点/输出格式三段关键词；其余提示词保留原有占位符（逐个 key 维护必需占位符列表）。

### 前端（apps/web）

新增「提示词设置」页（侧边导航进入）：

- 左侧：类型列表，打标分组展开 21 学科；
- 右侧：大文本编辑器 + 字符数/估算 token；
- 按钮：保存、恢复默认、历史、回滚、查看差异；
- 显示当前 revision、sha1、更新时间；
- 保存前二次确认「将影响之后的新任务」。

## 四、验收

1. 改 `structure` 提示词 → 新任务结构调用使用新内容，旧任务不受影响；
2. 改 `tagging:senior-math` → 数学习题打标使用新前缀；
3. 回滚到上一版 → 再新建任务使用旧内容；
4. 恢复默认 → 使用仓库默认；
5. 重启服务后覆盖仍生效；
6. 单测：读取覆盖、保存历史、回滚、占位符校验。

## 五、注意

- 打标前缀改动会使模型缓存失效，属预期；
- 长文本编辑器需防误删，保存前做基本结构校验；
- 覆盖文件在 data 目录，生产容器挂载 proddata 卷后同样生效。
