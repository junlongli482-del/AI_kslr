# 快速录入 MVP 实施说明

交付日期：2026-10-15。批准基线为 `docs/快速录入-MVP需求文档.md` 与 `docs/快速录入-MVP开发文档.md`；本文记录实际实现与后续边界，不把设计设想当成已交付能力。

## 可运行结构

- `apps/api`：Java 21、Spring Boot 3.5.16、MyBatis-Plus 3.5.12、Flyway。PostgreSQL 17 保存任务、审核版本、题目版本、试卷引用、原卷模板和处理事件。
- `apps/ai`：Python 3.12、FastAPI；官方 MinerU 上传、轮询、原包解析、紧凑中间数据、GPT 结构化、答案分组与匹配、补缺、坐标和裁图。
- `apps/web`：Vue 3、TypeScript、Element Plus、Tiptap、MathLive、KaTeX。用户编辑渲染后的内容，无须编辑 JSON。
- 本地地址 `http://127.0.0.1:5173`；API 8090、内部 AI 8091、数据库 55436。当前为本机单操作员工作台，未接正式平台的学校权限、账号和生产部署。

## 已核实服务

MinerU 使用官方服务和完整多页文件上传。两条 GPT 渠道均使用用户指定的 `https://gpt.huaiapi.xyz/v1` 与 `gpt-6.1-sol`，分别读取低价／稳定密钥，支持优先顺序和失败回退。低价渠道完成真实试卷结构化、答案提取和匹配；稳定渠道完成实际调用及 Word／图片衍生材料流程。密钥仅在受忽略的根目录 `.env`。

## 实施选择与差异

1. **原卷预览**：本版由 PDFium 渲染原始物理页，前端用页面图片加 SVG 框覆盖层。无需把每页独立提交 MinerU，也不重新排印教辅。坐标归一化，保留物理页尺寸；尚未采用设计中的 PDF.js 原生画布。
2. **内容协议**：Markdown／LaTeX 为可移植内容，`editor_documents` 保存 Tiptap 富文本结构；两者随编辑一起保存。本版未单独实现完整教育题目 AST。`QuestionPreview` 同时渲染题干、选项、小问、答案、解析和评分标准。
3. **题框**：印刷内容来自 MinerU 块坐标；跨栏和跨页保留多区域，重叠区域归并。OCR 漏掉的块间图像可从原页墨迹补图并标记待核对。主观题另外推定作答空白区，`purpose=response`，与有来源的内容框区分；不是已验证的学生作答配准结果。
4. **答案**：先区分试卷／章节，再提取到每个顶层题号。若模型把连续题号合并，二次拆分并验证覆盖完整后再匹配。匹配采用试卷、题号、题意与小问，保留无关条目。略、图略、理由略不补编。
5. **目录与标签**：正式知识点／章节目录明确显示未配置；基础属性和自由扩展标签可编辑并保存。统一属性定义注册、目录版本校验、教材映射和多层候选检索仍需在正式数据接入时实现。没有伪造正式知识点 ID。
6. **去重与授权**：保存来源、文件哈希、题目内容哈希、版本和未确认授权状态；未交付完整去重候选工作流或授权管理。重要程度算法未启用。
7. **任务恢复**：保留 MinerU 批次、原包、归一化结果与按输入摘要缓存的 AI 阶段。重试可复用结果；已有人工稿不会被重跑静默覆盖。首版是有限线程并发，无跨机器分布式租约与消息队列；资料过大时返回上下文预算提示，尚未交付无限长资料自动分批。
8. **版本**：审核稿使用乐观锁；事务入库按任务＋审核版本幂等。库列表显示当前版本，旧版本详情和试卷引用保留。裁图按坐标摘要生成独立文件，避免修改题框覆盖历史裁图。

## 资产与协议

`data/` 保存上传源文件、识别压缩包、Markdown、布局、图片、阶段状态、AI 调用记录、结果、裁图与测试证据；不纳入版本控制。`docs/contracts/quick-entry/` 提供当前 JSON Schema 和 API 描述。Python 使用 `uv.lock` 和已验证的 `requirements.lock.txt`；Java 使用 Maven Wrapper；前端使用 pnpm 锁文件。

## 明确边界

本版完成录入、可视化核对与入库闭环。学生卷拍照／扫描对齐、识别学生作答、批阅、正式知识点目录及教材映射、平台多租户和生产权限均未接入。原卷模板明确保存 `scan_capability=not_integrated`。没有真实手机照片畸变测试，不以 PDF 衍生 PNG 冒充实拍测试。
