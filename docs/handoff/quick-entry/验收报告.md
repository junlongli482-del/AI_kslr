# 快速录入 MVP 验收报告

日期：2026-10-15。结论：**本地 MVP 的识别—编排—审核—入库闭环已跑通，可用于真实样本试用；不代表逐题内容已由人工审核，也不代表扫描批阅已上线。**

## 打开与试用

工作台：`http://127.0.0.1:5173`。真实任务名称为“金版数学九上 · 期中与期末”。进入对照审核可以修改正文、公式、选项、小问、答案、解析、属性和题框；题库、试卷库已保存对应结果。三个名称含“衍生验证”的任务是明确标记的格式／答案形态测试，不是新增真实教辅。

重启：在项目根目录运行 `powershell -ExecutionPolicy Bypass -File scripts/start.ps1`。依赖与配置步骤见根目录 README。

## 真实样本结果

| 项目 | 实际结果 |
|---|---|
| 用户提供资料 | 两份各4页试卷＋1页共用答案，全部通过官方 MinerU；多页卷整体提交 |
| 结构化 | 期中23题、期末23题，共46道顶层题；保留选项和小问 |
| 答案关联 | 初稿18/46；修复连续题号合并条目后46/46有关联；16条无关答案未采用 |

| 坐标与裁图 | 68个区域，其中16个为额外推定的作答空白区；均可对照和编辑 |
| 典型边界 | 期中6、20题跨栏，期末21题跨物理页；期末1题四图选项、7题同行双图 |
| 漏图修复 | 期中5题图形不在 MinerU 内容块中，从原卷块间墨迹补回；前端明确提示核对 |

“46/46有关联”不是“答案准确率100%”。关联覆盖、结构合法与学科内容正确是不同指标。未独立人工逐题校验所有公式、数字、表格内容和答案数学正确性。逐题结构及来源记录见 `逐题检查清单.csv`。

真实任务的8次模型调用合计返回usage 201,883 token、累计调用耗时1,074.81秒；这是开发试跑累计值，包含初稿与修复，并非单次正式录入耗时。渠道没有提供可核实账单费用，本报告不填虚假金额。

- 浏览器：正文与公式保存、题框拖动和裁图刷新、确认状态、规则检查、增删拆合排序、答案重匹配、入库、库内详情和重复提交均通过；无捕获到的页面异常。
- 桌面与390px窄屏截图在 `screenshots/`。窄屏支持原卷展开／收起，原卷支持定位本题放大。

## 限制与下一阶段

1. 这是本地独立单操作员MVP，尚未合入正式教学平台的账号、学校权限和部署体系。
2. 原卷坐标模板已保存；学生扫描／拍照配准、识别作答和实际批阅未接入，模板明确标注 `not_integrated`。
3. 作答空白区域由相邻题和版面边界推定。印刷内容框和推定作答框都需要最后审核；遇到复杂多栏、特殊排版可手动补框。
4. 正式知识点、教材映射、属性定义版本管理、完整去重授权流程及重要程度算法没有伪造实现；当前有基础属性、来源、哈希、版本与自由扩展标签。
5. Word和PNG是明确标记的衍生材料；没有验证真实手机照片的透视畸变、模糊、遮挡或超长资料自动分批。

具体实现差异见 `IMPLEMENTATION-NOTES.md`。本报告不把上述待核对和未接入范围列为已完成能力。
